# Fonts Directory

Drop your official font files here:
- `google-sans-400.woff2` (Weight 400 - Regular)
- `google-sans-500.woff2` (Weight 500 - Medium)

The site will automatically load them via `@font-face` in `globals.css`. If the files are omitted, the font stack falls back seamlessly to `"Product Sans", ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif` without failing or delaying layout.
